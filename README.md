# Lokesh Kumar — Developer Portfolio

A clean, responsive personal portfolio showcasing my skills, projects, experience, education, certifications, and contact information.

🌐 **Live Portfolio:** (https://lokesh-portfolio-ten-bice.vercel.app/

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Light / dark theme
- Projects, Skills, Experience, About and Contact sections
- Resume view and download options
- GitHub, LinkedIn and LeetCode links
- Interactive API console
- Email contact functionality
- Toast notifications

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- HTML5
- CSS3
